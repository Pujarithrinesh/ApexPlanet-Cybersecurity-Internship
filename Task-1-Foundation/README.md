# Task 1 — Foundation & Environment Setup

**Program:** ApexPlanet Cybersecurity & Ethical Hacking Internship  
**Timeline in internship PDF:** Days 1–12  
**Objective:** Build fundamentals in cybersecurity, networking and cryptography, and configure a professional security lab.

## Scope from the internship brief
1. Cybersecurity basics: CIA Triad, common threats and attack vectors.
2. Lab setup: VirtualBox or VMware, Kali Linux, Metasploitable2 or DVWA, and a private lab network.
3. Linux fundamentals: navigation, permissions, packages and networking commands.
4. Networking: OSI, TCP/IP, DNS, HTTP/HTTPS, IP addressing, subnetting and NAT.
5. Cryptography: symmetric/asymmetric encryption, hashing, certificates, TLS and OpenSSL.
6. Tool familiarization: Wireshark, Nmap, Burp Suite and Netcat.

## Deliverables
- Lab setup report with screenshots of Kali, the target VM and a Wireshark test capture.
- GitHub notes and a Linux cheat sheet.
- Five-minute video walkthrough of the lab setup.
